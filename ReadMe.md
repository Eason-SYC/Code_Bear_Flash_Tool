# Code Bear Flasher 🐻⚡

A professional, modern Web-based flasher for ESP32 and ESP8266 devices.

## Features
- **Modern Dashboard**: Clean, intuitive interface for managing your ESP devices.
- **Glassmorphism UI**: Beautifully designed with professional aesthetics and Dark Mode support.
- **Mascot Guided**: Let the Code Bear guide you through the flashing process.
- **Integrated Terminal**: Real-time system logs and interactive Serial Monitor.
- **One-Click Flashing**: Simplified workflow for rapid prototyping.

## Quick Start
1. Run `start_server.bat` to launch a local server.
2. Open `http://localhost:8080` in a Web Serial supported browser (Chrome, Edge, Opera).
3. Connect your device and start pouring some honey (flashing)!

## Technology
- Core: [esptool-js](https://github.com/espressif/esptool-js)
- UI: Vanilla JS, CSS Grid/Flex, Font Awesome, Google Fonts (Inter)
- Terminal: [Xterm.js](https://xtermjs.org/)
